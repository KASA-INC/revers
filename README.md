# Revers

Film med kameraet – og se klippet baklengs.

- Spill av baklengs eller forlengs, med loop og lyd
- Gjør stemmen dypere eller lysere uten å endre tempoet
- Nedtelling før opptak
- Lagre videoen rett i en mappe du velger (Chrome), eller via deling på mobil
- Kan installeres som app i Chrome

Alt skjer lokalt i nettleseren. Ingen opptak sendes noe sted.

`server.py` er valgfri: den serverer appen lokalt og lagrer videoer i `videoer/` for nettlesere som ikke kan skrive til en mappe selv.
